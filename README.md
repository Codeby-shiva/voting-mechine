# voting-mechine
a voting mechine for collect vote and calculate and declare which party won


# Goal
This voting mechine program inspired from real voting mechine , This voting mechine can generate vote randomly or manually
as per your requirement


# Uses
- Put the number of votters those are able to contribute their votes

- Put two parties name 

- Put these parties hint.

-  By using the hint, votters can contribute their vote easily.

- Choose in which method you want to collect votes randomly or manually  (m - manually).
